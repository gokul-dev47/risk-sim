# Screenshots

Drop real PNG/JPG screenshots (or one GIF) here, then reference them from
the main `README.md`'s Screenshots section with:

```md
![Dashboard overview](docs/screenshots/dashboard.png)
```

Suggested shots (see main README for the exact placeholder list):
1. Dashboard overview — live transaction feed + KPI cards
2. What-If Simulator with the SHAP explanation panel open
3. Demo Scenario view mid-walkthrough, on the BLOCK decision
4. Drift Monitor panel showing a status flip (stable -> watch/retrain_recommended)

A short (10-20s) screen-capture GIF of the Demo Scenario walkthrough
(steps 1-4 in one clip) works well in place of screenshots 3 and 4 and is
usually more convincing to judges than static images.

Tools: ScreenToGif (Windows), Kap or Peek (macOS/Linux), or the built-in
OS screen recorder + ezgif.com/video-to-gif to convert. Keep each GIF
under ~5MB so it loads fast on GitHub.
